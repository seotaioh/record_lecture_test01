# 강의 자동 녹음기 (Auto Lecture Recorder)

macOS에서 **컴퓨터로 재생되는 강의 소리를 자동으로 녹음**해서 로컬 폴더(`~/강의녹음`)에 WAV 파일로 저장합니다.

- **완전 로컬 동작** — 인터넷 전송 없음, 어떤 계정에도 로그인/자동화하지 않음, 어디에도 업로드 안 함.
- **소리 감지 자동 녹음** — 소리가 나면 자동으로 녹음 시작, 조용해지면 자동 저장.
- **업로드용 소용량 사본 자동 생성** — 원본(무손실) + 16kHz 모노 사본(용량 1/6)을 함께 저장 → Tiro/Plaud 업로드에 바로 사용.

> ⚠️ **개인 학습용으로만 사용하세요.**
> - 본인이 수강 중인 강의를 **개인 복습용**으로 녹음하는 것은 일반적으로 문제가 없습니다.
> - 녹음물을 **공유·업로드·재배포하면 저작권 침해**가 될 수 있습니다. 절대 하지 마세요.
> - 다수 강의 플랫폼은 이용약관에서 녹화·녹음을 금지합니다. **사용 전 해당 플랫폼 약관을 확인하세요.**
> - 이 프로그램은 네트워크 전송이 없어 플랫폼에 신호를 보내지 않지만, 약관 위반 여부는 사용자 책임입니다.

---

## 1단계. BlackHole 설치 (최초 1회, 무료)

macOS는 보안상 시스템 소리를 바로 녹음할 수 없어서, 소리를 넘겨주는 **가상 오디오 장치**가 필요합니다. 무료 오픈소스인 **BlackHole**을 씁니다.

### 설치 방법
1. 아래 페이지에서 `BlackHole 2ch` 설치 파일(`.pkg`)을 내려받습니다.
   👉 https://existential.audio/blackhole/  (또는 https://github.com/ExistentialAudio/BlackHole/releases )
2. 내려받은 `.pkg` 를 더블클릭 → 안내에 따라 설치 (Mac 로그인 비밀번호 입력이 필요합니다 — macOS 자체 요구).
3. 설치 후 확인:
   ```bash
   ./run.sh --list
   ```
   목록에 `BlackHole 2ch (입력2)` 이 보이면 성공입니다.

## 2단계. 소리를 들으면서 동시에 녹음되게 설정 (다중 출력 장치)

BlackHole로만 소리를 보내면 **스피커로는 소리가 안 들립니다.** 스피커로 듣기 + 녹음을 **동시에** 하려면 "다중 출력 장치"를 만듭니다.

1. `오디오 MIDI 설정` 앱 실행 (Spotlight에서 "Audio MIDI Setup" 또는 "오디오 MIDI" 검색)
2. 왼쪽 아래 `＋` → **다중 출력 장치 생성**
3. 오른쪽 목록에서 다음 두 개를 체크:
   - ☑ `MacBook Pro 스피커` (또는 사용 중인 스피커/헤드폰)
   - ☑ `BlackHole 2ch`
4. (권장) `MacBook Pro 스피커`를 "주 장치(Primary)"로, 두 장치 모두 "드리프트 보정" 체크
5. 이름을 알아보기 쉽게 변경 (예: `녹음+스피커`)

### 녹음할 때 시스템 출력 전환
- 강의를 녹음할 때만: 메뉴바 스피커 아이콘(또는 `시스템 설정 > 사운드 > 출력`)에서 출력을 **`녹음+스피커`(다중 출력 장치)** 로 변경
- 녹음이 끝나면 다시 원래 스피커로 돌려놓으면 됩니다.

> 💡 이 전환이 번거로우면, 녹음할 때만 켜면 됩니다. 평소엔 일반 스피커로 두세요.

---

## 3단계. 실행

터미널에서 이 폴더로 이동한 뒤:

```bash
# 자동 녹음 (소리 감지 → 자동 시작/저장) — 기본 모드
./run.sh

# 연속 녹음 (Ctrl+C 누를 때까지 통째로 하나의 파일)
./run.sh continuous

# 오디오 장치 목록 확인
./run.sh --list
```

- 녹음 파일은 `~/강의녹음/` 폴더에 `강의_2026-08-03_14-22-05.wav` 형식으로 저장됩니다.
- 종료: `Ctrl + C`

### 저장 폴더를 바꾸고 싶다면
```bash
./run.sh auto --dir ~/Desktop/내강의녹음
```

## 4단계. Tiro / Plaud로 전사·요약하기 (선택, API 불필요)

녹음된 WAV 파일을 **Tiro나 Plaud 앱에 직접 불러오면** 자동 전사 + AI 요약노트가 만들어집니다. API 키·패스키 설정이 전혀 필요 없고, 평소 쓰던 대로 **구글 계정 로그인**만 하면 됩니다.

### Tiro 사용 시
1. Tiro 앱/웹 로그인 (구글 계정)
2. 새 노트 → **오디오 파일 가져오기(불러오기)** 로 `~/강의녹음/강의_….wav` 선택
3. 자동으로 전사 + 요약노트 생성

### Plaud 사용 시
1. Plaud 앱 로그인 (구글 계정)
2. **파일 가져오기(Import)** 로 WAV 선택 → 전사/AI 요약 생성

> 📌 **여기서 처음으로 파일이 클라우드로 올라갑니다.** 녹음 자체는 로컬이지만, 전사를 위해 회원님이 직접 올리는 순간 Tiro/Plaud 서버로 전송됩니다. (두 서비스 모두 이미 유료로 쓰시는 것이라 문제없지만, 흐름상 알고 계시라고 명시합니다.)

### 파일 용량 (자동으로 소용량 사본 생성)
- WAV(무손실)는 48kHz 스테레오 기준 **약 11MB/분** → 1시간이면 약 650MB로 큽니다.
- 그래서 녹음할 때마다 **업로드용 소용량 사본**을 `~/강의녹음/업로드용/` 폴더에 자동으로 함께 저장합니다.
  - 형식: **16kHz 모노 WAV** (말소리 전사 표준) — 용량 **약 1/6** (1시간 ≈ 110MB), 전사 품질은 거의 동일
  - **Tiro/Plaud에는 `업로드용/` 폴더의 파일을 올리면** 빠르고 가볍습니다. 원본은 `~/강의녹음/`에 무손실로 보관됩니다.
- 사본이 필요 없으면 `./run.sh --no-upload-copy` 로 끌 수 있습니다.

## 동작 방식 (자동 모드)

```
소리 감지(볼륨이 기준 이상)  →  ● 녹음 시작
   … 강의 재생 중 계속 녹음 …
3초 이상 조용해짐            →  ■ 파일 저장, 다시 대기
```

- 2초보다 짧은 녹음은 잡음으로 보고 버립니다.
- 소리가 다시 나면 새 파일로 다시 녹음합니다.

## 설정값 조정

`recorder.py` 상단의 값을 바꿔 미세 조정할 수 있습니다.

| 값 | 의미 | 기본값 |
|----|------|--------|
| `SILENCE_THRESHOLD` | 이 볼륨 이하는 '조용함'으로 판단 (0~1). 녹음이 자꾸 끊기면 낮추고, 조용한데 계속 녹음되면 높이세요 | `0.008` |
| `SILENCE_TIMEOUT` | 몇 초 조용하면 저장할지 | `3.0` |
| `MIN_CLIP_SECONDS` | 이보다 짧으면 저장 안 함 | `2.0` |
| `SAVE_DIR` | 저장 폴더 | `~/강의녹음` |
| `SAMPLE_RATE` | 샘플레이트 | `48000` |
| `MAKE_UPLOAD_COPY` | 업로드용 소용량 사본 생성 여부 | `True` |
| `UPLOAD_SAMPLE_RATE` | 사본 샘플레이트 (말소리 표준 16kHz) | `16000` |

## 문제 해결

- **`BlackHole 입력 장치를 찾지 못했습니다`** → 1단계 설치가 안 됐거나, 설치 후 터미널을 새로 열지 않았습니다. `./run.sh --list` 로 확인하세요.
- **녹음은 되는데 소리가 안 들려요** → 2단계 다중 출력 장치를 안 만들었습니다. 출력을 `녹음+스피커`로 바꾸세요.
- **파일이 무음(0에 가까움)이에요** → 시스템 출력이 BlackHole/다중출력장치로 되어 있는지 확인하세요.
- **너무 잘게 쪼개져요** → `SILENCE_TIMEOUT`을 크게(예: 6.0), 또는 `continuous` 모드를 쓰세요.
